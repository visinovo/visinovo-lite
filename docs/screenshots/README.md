# Screenshot-Platzhalter

Die Dateien in diesem Ordner sind **Platzhalter** und müssen vor der
Veröffentlichung durch echte Screenshots der aktuellen
Release-Version ersetzt werden (gleiche Dateinamen).

Empfohlene Aufnahmen (jeweils ohne personenbezogene Daten,
idealerweise mit Beispieldaten):

| Datei | Inhalt |
|---|---|
| `dashboard.png` | Dashboard nach dem ersten Start (Zähler „x / 3", Hinweis auf lokale Daten) |
| `listing-form.png` | Listing-Formular (Titel, Beschreibung, Tags …) |
| `analysis-result.png` | Analyse-Ergebnis (Qualitätsscore, Teilbewertungen, Vorschläge) |

Hinweise:

- Fenster-/Oberflächengröße wie vom Endnutzer zu erwarten
  (640–1280 px Breite).
- Vor der Aufnahme: lokale Daten zurücksetzen
  (*Einstellungen → Daten zurücksetzen*), damit keine
  Beispiel-/Testdaten sichtbar sind.
- Sensitive Inhalte (eigene Shopnamen, Markennamen) aus dem
  Screenshot entfernen.
- Die Platzhalter sind bewusst als solche gekennzeichnet
  („Screenshot-Platzhalter …").
